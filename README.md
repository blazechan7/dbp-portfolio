# Portfolio

Personal portfolio for Fontys ICT Open Learning student.  
Editorial-style static site showcasing work, background, personal interests, and how to get in touch via the site itself.

**Live site:** [dbputeri.com](https://dbputeri.com/)

---

## Explore the website

Use the top navigation on every page:

| Page | What you’ll find |
|------|------------------|
| **Home** | Magazine-style cover, short intro, featured projects, and a link to all work |
| **About** | Who I am, skills, experience, and resume & CV (PDF) |
| **Work** | Six projects with descriptions and links to live demos |
| **Playground** | Games, streaming, travel, and food — interests outside core work |
| **Contact** | Email and links to LinkedIn, GitHub, work, and PDFs |

**Tips**
- On **Work**, click a project image or **View live site** to open that project in a new tab.
- On **About**, use **View resume (PDF)** or **View CV (PDF)** to open hiring documents.
- On **Home**, a short cover video may play; page animations use an internet connection.
